# PITLABS Website Prototype
Prototype frontend responsive PT. Pulau Inovasi Teknologi.

## Menjalankan
- Extract ZIP.
- Buka `index.html` dengan browser (Chrome/Edge).
- Logo ada di `logo-pitlabs.png`.

## Fitur demo
- Home, katalog, filter/search, detail produk.
- Beli via Shopee confirmation (URL toko belum disambungkan).
- Rental checkout, durasi, QRIS/VA/COD pilihan.
- Invoice digital dan QR placeholder.
- Admin dashboard: order list, manual status payment/pickup, inventory, finance overview.
- AI chat mock.

## Catatan
Ini frontend prototype. Data disimpan sementara di memori browser dan reset saat refresh.
Belum ada backend/database, autentikasi aman, payment gateway, QR scanner nyata, WhatsApp scheduler, Shopee redirect, CRUD persisten, perhitungan denda terverifikasi, atau real-time unit reservation. Untuk produksi, implementasikan API + database dan integrasi pihak ketiga.
