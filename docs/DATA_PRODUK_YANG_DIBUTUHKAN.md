# Data yang Perlu Dilengkapi

Frontend tidak boleh mengarang spesifikasi, harga, atau kebijakan. Semua yang tampil "Informasi belum tersedia" menunggu data berikut. Cari penandanya dengan: `grep -r "data-needs-data" resources/views`.

## Per produk (7 produk)
Laptop · Raspberry Pi 5 · Jetson Orin Nano · Drone · Kamera Mirrorless · Google Colab Pro · Google Colab Pro Plus

| Data | Keterangan |
|---|---|
| Foto | Minimal 1 foto per produk (rasio 4:3), format JPG/WebP, beserta teks alternatif |
| Deskripsi | 1–2 paragraf |
| Spesifikasi | Pasangan label dan nilai |
| Fungsi | Kegunaan untuk pelanggan |
| Panduan penggunaan | Singkat |
| Harga sewa | Per hari (dan per minggu/bulan jika berbeda) |
| Harga jual | Jika produk dijual di Shopee |
| Dijual / disewakan | Apakah tombol Beli, Sewa, atau keduanya tampil |
| URL Shopee | Per produk |
| Perangkat fisik | Jumlah unit dan format kode unit |
| Layanan digital | Cara aktivasi, batas slot/kuota |

## Kebijakan mitra (berlaku semua produk)
Alamat dan jam operasional lokasi pengambilan · email dan WhatsApp · nominal denda per kategori kerusakan (ringan, sedang, berat) · tarif denda keterlambatan · deposit · durasi sewa minimum dan maksimum · waktu tahan unit sebelum pembayaran · kebijakan pembatalan dan refund · aturan perpanjangan · prosedur keberatan denda · pilihan payment gateway.
